# good-fella.com 深度拆解

> 渲染方式：真实 Chromium 渲染（CDP）。桌面 1440×900 DPR1，移动 390×844 DPR1，实测 2026-11-05。
> 站点栈：Next.js（`__NEXT_DATA__`）+ **Lenis** 平滑滚动（字符串与 `html.lenis` 类双验证）+ 3 个 canvas + 28 张 img。
> 滚动机制：`body{position:fixed}` + JS 虚拟滚动（与 digilab 相同），`uninstrument()` 解除后原生 `scrollY` 可推进。
> 截图说明：桌面首屏 99.5% 纯色（preloader 覆盖层，`Loading…` 文字 16px）→ 解锁后拍得 4/5 有效；移动 4/4 有效。

## 2. Token 实测

### 2.1 字体

**两族分工**：
- `aktiv-grotesk` —— 所有标题 + 正文（13.7–87.64px）
- `geistMono` —— 所有元信息/标签（13.7–19.74px），含 `// Process`、`Contact`、`Menu`、项目名 `Powerade`

**字重**：300 / 400 / 500 三档。H1 用 400 / 300（不是粗体！），导航 500，正文 400，标签 400。

**字距**：展示级 **−0.035em**（87.64 → −3.067；60.34 → −3.017；31.48 → −0.787），等宽标签 **−0.016~−0.02em**（19.74 → −0.395；15.74 → −0.315；13.74 → −0.275），正文 `normal`。

**行高**：H1 **1.0–1.1**（87.64/87.64 = 1.0 for w300；87.64/96.40 = 1.1 for w400）；H2 1.25（60.34/67.89）；正文 1.5（16/24）；等宽 1.0–1.5。

### 2.3 间距 / 栅格 / 最大宽度

- 无 max-width 容器（`maxW: []`）。
- 8 个 section，docH 11818px ≈ 13.1 屏；移动 10966px。
- Section 高度序列：**10918（hero+intro 合体）→ 900 → 706 → 3136 → 3912 → 850 → …**。hero 区 10918px 异常大（12 屏），内含 H1 + How we work + 工作列表。
- 无 CSS Grid 布局（grids 只有 `3.875px` 等微型 grid）。
- **圆角：0 档**（`radii: []`）。全站零圆角。
- **阴影：0 档**（`shadows: []`）。全站零阴影。
- 边框：未显著检出。

### 2.4 深度 / 层次

全站**零圆角 + 零阴影 + 零边框**。层次完全由**底色切换**（`#eeeeee` ↔ `#141314`）和**橙色蒙层**制造。这是"硬边平面"美学的极端实现。

## 4. 动效

- **库**：**Lenis**（唯一检出）。无 GSAP / three.js / Framer。
- **滚动模型**：`body{position:fixed}` + Lenis 虚拟滚动（与 digilab 同型）。
- **过渡曲线（实测 4 条）**：
  - `0.7s cubic-bezier(0.4, 0, 0.2, 1)` —— **标准 Material ease**（主曲线，最多）
  - `0.3s cubic-bezier(0.4, 0, 0.2, 1)` —— 快速版本
  - `0.7s cubic-bezier(0.625, 0.05, 0, 1)` — 自定义，慢起快收
  - `0.7s cubic-bezier(0.83, 0, 0.17, 1)` — ease-in-out 极端对称
- **keyframes**：仅 `pulse 2s ease-in-out`。
- **与第一批对比**：good-fella 是唯一用**标准 Material 曲线** `cubic-bezier(0.4, 0, 0.2, 1)` 做主曲线的站。digilab / nfinitepaper 用带过冲的自定义曲线（y1=1.08），pear 用 easeOutQuint 类（0.22, 1, 0.36, 1），maxmilkin 用急停曲线（0.11, 0.82, 0.39, 0.92）。good-fella 选择了最"中性"的曲线，没有署名手感。

## 5. 它"为什么好"（3 条可迁移原则）

1. **零圆角 + 零阴影 + 零边框 + 1 个强调色，层次全靠底色切换和 alpha 蒙层**。实测全站无 `border-radius`、无 `box-shadow`、无 `border-width`，层次由 `#eeeeee`（浅底）↔ `#141314`（深底）切换 + 3 档橙色 alpha 蒙层（6% / 10%）制造。迁移规则：**想做"硬边平面"风格时，把圆角/阴影/边框三件套全部归零，用 2 个底色 + 1 个强调色的 2–3 档 alpha 做全部层次 —— 任何圆角或阴影都会破坏这种语言的一致性**。

2. **标题用 aktiv-grotesk 400/300（不是 bold），导航用 500，靠字重倒置制造反差**。实测 H1「The digital landmark studio.」字重 400，而导航「Home」是 500 —— 导航比标题还粗。这是反直觉的层级安排，但效果是"标题像印刷品、导航像操作按钮"，两种文字性质分明。迁移规则：**不一定要按"标题最粗、正文最细"的惯例排字重；把标题降到 300–400、操作元素升到 500，用字重的"用途角色"代替"层级"做区分**。

3. **等宽字体只写项目名和元信息，且全部加 `//` 前缀或全大写**。实测 `geistMono` 出现在：`// Process`、`Powerade`、`Contact`、`Menu`、`Working Globally`、`Just launched` —— 全部是"标注/标签/项目名"，从不用于正文。且有 `// Process` 这样的注释式前缀。迁移规则：**等宽字体的用途应该被严格限定为"代码注释式的元信息"，加 `//` 或 `[]` 前缀让它读起来像注释而非内容；任何一段超过 2 行的等宽文本都说明越界了**。

## 6. 不能照抄的地方

1. **`body{position:fixed}` + Lenis 虚拟滚动**与 digilab 同型，无头环境原生滚动完全失效，所有可访问性隐患（JS 失败、输入法、手势冲突）都继承。
2. **hero 区 10918px（12 屏）**异常大，内含 H1 + 工作流程 + 项目列表，但信息量只有 3 个概念。移动端 10966px 同样。长滚动 + 低密度 = 高跳出率。
3. **`#818081` 次要文字在 `#eeeeee` 浅底上**对比度约 3.5:1，低于 WCAG AA 4.5:1。深底 `#141314` 上的 `#818081` 更差（约 2.8:1）。次要信息可读性不达标。
4. **首屏 preloader 覆盖层不自动退场**（实测 99.5% 纯色，需要手动 `display:none`）—— 可能是 Lenis 初始化依赖某个事件在无头环境未触发。真实用户如果遇到同样竞态会看到永久的 Loading 屏。
5. **H1 87.64px 负字距 −0.035em + 行高 1.0**：与 pear 一样，负行高 + 负字距只适合短行拉丁标题。CJK 下需要 +0.2~0.3 行高且禁负字距。
6. **全站零圆角零阴影**是风格选择，但在需要浮层、弹窗、下拉菜单的产品界面里会完全失去层级手段。这是 agency 作品集的特赦，不是产品设计的通用方案。
